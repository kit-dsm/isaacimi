# Building the documentation

We use [mkdocs](https://www.mkdocs.org/) with the [mkdocs-material](https://squidfunk.github.io/mkdocs-material/) theme, along with various plugins to create our documentation.

To view the docs locally, run the `serve.sh` script to install the pip packages and start the built-in dev server. We recommend creating a Python virtual environment before running the script.
